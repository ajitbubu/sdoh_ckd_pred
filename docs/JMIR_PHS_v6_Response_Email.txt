1. CORRECTIONS IDENTIFIED DURING REVISION

To address the concern that the analysis was not rigorous enough, we re-ran the complete pipeline from the public raw data. In doing so we identified errors in the previous version, which we have corrected:

- Model comparison: the previously reported advantage of XGBoost over logistic regression was not supported. With identical imputation and cross-validation, the AUROC difference is -0.004 (95% CI -0.026 to 0.003).
- Calibration: a binning error overstated calibration. The corrected logistic calibration slope is 0.75 (95% CI 0.70-0.80), which we now report and discuss.
- Stage 1 values: several values in the text did not match the figures. We re-ran Stage 1 from the released code with the Neighborhood Atlas ADI file, regenerated the figures, and report the resulting values throughout.
- Withdrawn analyses: analyses we had described but not completed (the Census-crosswalk sensitivity analysis, the feature ablations, and a Spearman correlation), a reference to a prospective evaluation protocol, a reference to an archived data snapshot, and the statement that race/ethnicity was not a model predictor (it is) have been removed or corrected.
- Confidence intervals: all confidence intervals are now design-based, estimated with a Rao-Wu bootstrap that resamples NHANES primary sampling units within strata.

Every number in the revised manuscript is produced by code in the public project repository, archived in Zenodo at submission. We regret these errors.

2. CORRECTION REGARDING GENERATIVE AI

A previous version of our manuscript stated that no generative AI tools were used in its preparation. That statement was incorrect, and we apologize for it. The revised manuscript includes a "Use of Generative AI" section disclosing that Claude (Anthropic) was used to help write and debug analysis code, to draft and edit manuscript text, and to check reported values against analysis outputs. The authors reviewed, edited, and verified all AI-assisted content, re-ran all analyses, and take full responsibility for the content of the article.

REVIEWER FE MAJOR 4: PLACES measures self-reported diagnosed CKD, a different construct, and under-ascertainment is socially patterned.

RESPONSE: We thank the reviewer for this important point, which we have adopted throughout. The Abstract, Methods, Discussion, Limitations, and Conclusions now state that the Stage 1 outcome is the prevalence of self-reported diagnosed CKD, a different construct from the laboratory markers used in Stage 2, and the PLACES construct is now the first limitation discussed.

REVIEWER FE MAJOR 7: The XGBoost-versus-logistic-regression comparison is invalid (DeLong assumptions; different imputation).

RESPONSE: We agree with both points and have replaced the comparison. DeLong's test has been removed and no P values are reported. XGBoost and logistic regression are now compared under the same median imputation fitted within each training fold, alongside the primary XGBoost model with native missing-value handling. Uncertainty is estimated as the reviewer suggested, by re-running the full 5-fold cross-validation inside each of 1,000 bootstrap replicates that resample NHANES primary sampling units within strata.
Under identical imputation, the AUROC difference (XGBoost minus logistic regression) was -0.004 (95% CI -0.026 to 0.003). REVIEWER FE MAJOR 8: The outcome is not a KDIGO CKD diagnosis, and the one-component inclusion criterion creates differential misclassification.

RESPONSE: We agree. (a) The outcome is now described as single-visit laboratory markers of CKD, and the Methods state that it is not a KDIGO diagnosis because the 3-month chronicity criterion cannot be applied. The Limitations note that transient abnormalities inflate prevalence and probably lower measured discrimination. (b) Of 15,150 participants, 13,666 had both components, 249 had serum creatinine only, and 1,235 had urine measures only. Because the outcome is positive if either criterion is met, missing components can only produce false negatives, biasing prevalence downward. Restricted to participants with both components, prevalence was 13.8% and AUROC was 0.775 (95% CI 0.760-0.791), or 0.769 when the model was refit on that subset. We report these results and discuss the direction of the bias in the Limitations.
Location: Abstract; Methods, Stage 2 outcome; Results, Stage 2; Discussion, "Limitations".
